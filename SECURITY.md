# Security

Please report a suspected vulnerability privately to the repository owner before opening a public issue. Include the affected version, reproduction steps, and the minimum sample data needed to demonstrate the problem.

Do not include real prompts, source code, command output, credentials, or complete session files in a report. Use a minimal synthetic JSONL fixture instead.

Glido has no runtime dependencies. AI interpretation is opt-in and requires an API key supplied through the environment; the project does not store that key.
